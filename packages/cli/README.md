# @framescout/cli

Command-line interface for Framescout. Ships the `framescout` binary
with subcommands for interactive setup (`init`), config validation
(`config validate`, `config schema`), and pipeline smoke tests
(`test sinks`, `test pipeline`).

**Status:** v0.1 skeleton. Real subcommands land in a later phase; see
`docs/V0.1-SCOPE.md §5` for the v0.1 CLI surface.
