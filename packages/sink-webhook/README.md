# @framescout/sink-webhook

Framescout **Sink** plugin: posts the canonical observation as JSON to
a configurable webhook endpoint. Bearer-token auth, custom headers.
The natural target for n8n / Make / Zapier-style consumers and
self-hosted aggregators.

**Status:** v0.1 skeleton. Real implementation lands in a later phase;
see `examples/n8n-webhook/` (coming with v0.1) for a sample workflow.
